## Why the MultiStepMPC didn't work

The MPC plans 5 model switches within a window, but only one model runs per window. Steps 1–4 are ghost decisions that never execute. The switching costs penalize transitions that never happen. The per-step predictions are useful, but not as 5 separate decision points — they're 5 estimates of difficulty at different moments within a single 15-second decision window.

## Better approach

Use the 5 per-step predictions to make a **single, smarter decision** per window. The key insight: per-step predictions show how difficulty evolves within the window. A flat average throws this away. These controllers exploit the temporal structure without pretending to make 5 decisions.

## Controllers to implement

All controllers below output ONE model selection per window (same interface as DirectThreshold).

### 1. DirectThreshold (baseline, unchanged)
Uses averaged predictions. Exactly as in existing code.

```python
def direct_threshold(df, T, mn, ms):
    for _, r in df.iterrows():
        if r["pred_nano_avg"] < T - mn: select nano
        elif r["pred_small_avg"] < T - ms: select small
        else: select medium
```

### 2. WorstCaseThreshold
Uses the MAX predicted miss rate across the 5 steps instead of the mean. If any moment in the next 15 seconds might be hard, upgrade.

```python
def worst_case_threshold(df, T, mn, ms):
    for _, r in df.iterrows():
        nano_worst = max(r["pred_nano_s0"], ..., r["pred_nano_s4"])
        small_worst = max(r["pred_small_s0"], ..., r["pred_small_s4"])
        if nano_worst < T - mn: select nano
        elif small_worst < T - ms: select small
        else: select medium
```

Rationale: A single hard moment within the window means missed detections. Conservative but principled.

### 3. WeightedThreshold
Weights earlier steps more heavily because they're more accurate (s0: r=0.820, s4: r=0.782 from the per-step correlation analysis).

```python
# Weights: exponentially decaying
weights = np.array([0.35, 0.25, 0.20, 0.12, 0.08])  # sum = 1.0

def weighted_threshold(df, T, mn, ms):
    for _, r in df.iterrows():
        nano_w = sum(w * r[f"pred_nano_s{s}"] for s, w in enumerate(weights))
        small_w = sum(w * r[f"pred_small_s{s}"] for s, w in enumerate(weights))
        if nano_w < T - mn: select nano
        elif small_w < T - ms: select small
        else: select medium
```

Rationale: Earlier predictions are more accurate. Trust them more.

### 4. VarianceAwareThreshold  
Uses the average prediction, but when per-step variance is high (steps disagree), adds a safety margin proportional to the disagreement.

```python
def variance_aware_threshold(df, T, mn, ms, gamma):
    for _, r in df.iterrows():
        nano_steps = [r[f"pred_nano_s{s}"] for s in range(5)]
        nano_mean = mean(nano_steps)
        nano_std = std(nano_steps)
        nano_adjusted = nano_mean + gamma * nano_std  # shift up when uncertain
        
        small_steps = [r[f"pred_small_s{s}"] for s in range(5)]
        small_mean = mean(small_steps)
        small_std = std(small_steps)
        small_adjusted = small_mean + gamma * small_std
        
        if nano_adjusted < T - mn: select nano
        elif small_adjusted < T - ms: select small
        else: select medium
```

Rationale: High step variance = the scene is transitioning. Be conservative. Low step variance = stable scene, trust the average.

Grid search gamma: [0.0, 0.5, 1.0, 1.5, 2.0]
Note: gamma=0 reduces to DirectThreshold.

### 5. AnyStepThreshold
Selects the lightest model where ALL 5 steps predict miss rate below threshold. If any step predicts failure, upgrade.

```python
def any_step_threshold(df, T, mn, ms):
    for _, r in df.iterrows():
        all_nano_ok = all(r[f"pred_nano_s{s}"] < T - mn for s in range(5))
        if all_nano_ok: select nano
        else:
            all_small_ok = all(r[f"pred_small_s{s}"] < T - ms for s in range(5))
            if all_small_ok: select small
            else: select medium
```

Rationale: Similar to WorstCase but using the threshold directly. "Every moment must be adequate."

### 6. EnergyPenalty (renamed BayesMPC, stateless, for comparison)
The existing greedy selector using averaged predictions. Keep for comparison.

```python
def energy_penalty(df, lu, T):
    e_norm = {m: ENERGY[m] / E_MEDIUM for m in range(3)}
    for _, row in df.iterrows():
        pm = {0: row["pred_nano_avg"], 1: row["pred_small_avg"], 2: row["pred_medium_avg"]}
        best = argmin over m: e_norm[m] + lu * max(0, pm[m] - T)
```
